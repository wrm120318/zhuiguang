## 二、柔光玻璃材质系统 v6（全站统一）

### 2.1 设计哲学：磨砂，不是透明

大厂柔光玻璃的本质是 **"磨砂"**——像毛玻璃，有厚度、有磨砂颗粒感、边缘有反光，但**不是清水片**。

- **填充**：浅档 `rgba(255,255,255, 0.18~0.25)`（磨砂白，不是 0.12 清水）；深档 `rgba(40,33,22, 0.45~0.55)`（磨砂暗金）
- **backdrop-filter**：`blur(20px) saturate(180%)`（浅）/ `blur(22px) saturate(175%)`（深）
- **1px 亮边**：`rgba(255,255,255, 0.4)`（浅）/ `rgba(212,175,55, 0.3)`（深）——这是"玻璃边缘反光"的灵魂，不能删
- **阴影**：`0 8px 24px -8px rgba(120,90,30, 0.12)`（似有似无，负扩散）
- **关键**：玻璃后面必须有背景图透出，blur 才有事做

### 2.2 三级玻璃材质

| 级别 | 用途 | 填充（浅/深） | blur | 亮边 | 阴影 |
|------|------|--------------|------|------|------|
| **L1 主角** | Hero、弹窗、抽屉 | 0.18 / 0.45 | 20px | 0.4 / 0.3 | 0 8px 24px -8px |
| **L2 卡片** | 美文卡、学科卡、排行榜 | 0.22 / 0.5 | 18px | 0.35 / 0.28 | 0 6px 18px -6px |
| **L3 点缀** | 快捷入口、学科瓷片、标签 | 0.25 / 0.55 | 14px | 0.3 / 0.25 | 0 4px 12px -4px |

### 2.3 与 v4/v5 的区别

| 参数 | v4（白瓷） | v5（全透明塑料） | v6（磨砂玻璃） |
|------|-----------|----------------|---------------|
| Hero 填充 | 0.70 | 0.12（太透） | **0.18**（磨砂） |
| 卡片填充 | 0.92 | 0.22 | **0.22**（保持，但加强亮边） |
| 亮边 | 无 | 0.38（太弱） | **0.4~0.45**（边缘反光明显） |
| 背景图透出 | 被挡住 | 被 Hero 透没了 | **真正透出**（0.18 让纹理可见） |
| 视觉感受 | 白瓷片 | 透明塑料 | **磨砂玻璃** |

## 三、首页重设计：现代 / 美观 / 高端 / 大方 / 贴合主题

### 3.1 设计目标

打破"首页 = 一堆被框住的白卡堆叠"的旧范式，改为 **"开放釉光 + 玻璃浮层"** 的现代布局：

- **Hero 不再是卡片**：改为"浮在背景图上的开放釉光区"，无矩形边界、无大阴影，只有极淡的顶部釉光
- **内容浮在玻璃上**：文字、按钮、统计数字直接浮在背景图上，不需要卡片容器
- **背景图成为主角**：纹理、光斑、网格真正可见，玻璃只是"一层薄雾"

### 3.2 Hero 重设计（核心改动）

**当前问题**：`.hero` 是 `border-radius:32px` 圆角卡 + 背景 + 边框 + 阴影，像"背景上贴了一块玻璃片"。

**新设计**：
- **移除矩形边界**：`border-radius: 0`（或 `border-radius: 28px` 但无背景无阴影，纯文字浮在背景图上）
- **无填充无阴影**：Hero 本身不做玻璃面板，文字直接浮在背景图上
- **顶部釉光**：`inset 0 1px 0 rgba(255,255,255,0.5)` 极淡细线（似有似无）
- **文字排版**：大标题用衬线（600 字重），副标题 17px，间距宽松，呼吸感强
- **CTA 按钮**：胶囊形 `border-radius:999px`，主按钮金系渐变，次按钮玻璃描边
- **统计数字**：每个数字独立小玻璃片（L3 级别），2 列布局（移动端）

### 3.3 最新美文卡片重设计

**当前问题**：`.art-card` 用 `rgba(255,255,255,0.66)` 白瓷填充 + `0 34px 80px` 大阴影，矩形框明显。

**新设计**：
- **L2 玻璃**：填充 `0.22`（浅）/ `0.5`（深），blur 18px，亮边 `0.35`
- **阴影收敛**：`0 6px 18px -6px`（似有似无）
- **布局优化**：图片在上（圆角 16px），标题加粗，作者信息淡金色，下方留白合理
- **hover**：填充微升 `0.28`，阴影加深，上浮 2px

### 3.4 移动端适配重做

**当前问题**：hero 三列 stats + 大 padding + 滑动鬼畜。

**新设计**：
- **Hero 高度自适应**：`min-height: auto`，padding 收紧 `22px 18px 20px`
- **stats 改 2 列**：`grid-template-columns: repeat(2, 1fr)`，gap 10px
- **禁止横向滚动**：`overflow-x: hidden`
- **标题字号**：`clamp(22px, 6.5vw, 27px)`（不再过大）
- **CTA 按钮**：全宽或自适应，padding 12px 18px

## 四、全站墨金柔光玻璃重设计（其他页面）

### 4.1 统一应用材质系统

- **登录页**：弹窗用 L1 玻璃（0.18 磨砂 + 0.4 亮边）
- **学科页**：学科卡用 L2 玻璃（0.22 + 0.35 亮边）
- **排行榜**：奖牌图标保持，卡片用 L2 玻璃
- **后台**：表单卡片用 L2 玻璃，弹窗用 L1 玻璃

### 4.2 输入框矩形框处理（可选）

**当前**：`box-shadow: 0 0 0 1px rgba(186,117,23,0.2) inset`（墨金边框）。

**方案 A（推荐）**：保持边框，但改更弱 `0.12`（浅）/ `0.18`（深），输入框像"玻璃上的凹槽"。

**方案 B**：完全去掉边框，改纯背景玻璃 `rgba(255,255,255,0.08)`（浅）/ `rgba(40,33,22,0.3)`（深），输入框像"玻璃上的凹陷"。

**需要你拍板**：选 A（弱边框）还是 B（无边框）。

## 五、背景图优化（让它真正可见）

### 5.1 当前问题

v5 背景图纹理加强了，但 Hero 0.12 太透把背景图透没了，卡片 0.22 也偏透，所以"一点都没看出来"。

### 5.2 新方案

- **Hero 填充升到 0.18**：磨砂质感，背景图纹理透出但不被盖住
- **卡片填充保持 0.22**：磨砂白，背景图从卡片边缘透出
- **背景图纹理再加强**：网格 `0.07 → 0.09`，光斑 `0.20 → 0.24`，丝光 `0.75 → 0.85`（浅档；深档同比例）
- **Hero 区域背景图更亮**：在 Hero 下方加一个 `radial-gradient` 提亮区，让纹理在 Hero 处更明显

## 八、落地纪要（v3.0.0 / 2026-08-22）
