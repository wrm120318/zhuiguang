## 3. 三问题根因（修正版 · 全部限定「墨金学术模式」）

1. **花里胡哨** → 墨金首页 4 个高饱和漂浮光球 + 每卡重玻璃彩影，踩中 4.0 §2 三大根因（配色铺太满 / 背景不安静 / 毛玻璃滥用）。
2. **十分奇怪** → 62–76px 巨型渐变标题 + 漂浮光球 + 硬编码 emoji 三者视觉语言矛盾；且样式越界强加经典（铁律 2）。
3. **墨金首页衬线"没了"** → 衬线规则在墨金本就存在（其他墨金页正常），首页是**设计层把衬线高级感淹没** + CDN 字体加载可能不稳；修法是按墨金风格**刻意重新做回**衬线主导的克制排版，而不是"补一条全局规则"。

## 4. 重设计方向（铁律：两模式独立，改动只收口在墨金）

### 4.1 经典模式（橙色毛玻璃）—— 本版明确：**保持原样，像素级不动**

- 本次反馈不涉及经典模式；经典模式本就不用高级衬线。
- 由于当前 HomeView 的墨金液态玻璃越界污染了经典模式（铁律 2 违规），**本次须把越界样式全部回收到 `.zg-inkgold` 作用域**，使经典模式回到"未受液态玻璃影响"的干净橙调状态。（是否需要回退由决策点 D4 确认。）

### 4.2 墨金学术模式（克制为骨 · 活力为魂）—— 总纲

回归 4.0 定义的「克制」语言作为**骨架**（安静纸感底 + 沉稳金点睛 + 衬线标题 + 克制玻璃），但在此骨架上叠加「**活力**」与「**品牌**」——**不是**加更多高饱和光球 / 重玻璃（那会回到花里胡哨），而是用**克制的光语言 + 有目的的动态 + 品牌签名**让首页"活"起来且不阴郁、不死板。这正好落在已确认的 D2（多玻璃降饱和：保留玻璃质感但降饱和减数量，介于花哨 ↔ 克制之间），并回应你新增的要求：**现代化、高级、品牌、美观，还要有活力——活跃中带着沉稳，但不死气沉沉**。

### 4.3 设计语言：现代化 / 高级 / 品牌 / 活力（具体落地）

**4.3.1 品牌（追光 = 光）** —— 把"光"做成全站一致、可识别的签名母题
- Hero 上方一道**极细的金色光线 / 一束柔光**作为追光品牌母题；墨金下 = 暖金光，经典下 = 暖橘光（同一母题、两模式各表，互不串味）。
- 品牌字"追光"在 Hero tag / 页脚用统一 treatment（衬线 + 一束微光），形成记忆点。
- 金主色作为**唯一**强调色贯穿（描边 / 小色块 / 光线 / 强调点），不引入第二种跳跃色 → 品牌统一、克制。

**4.3.2 活力（不死气沉沉）** —— 用"有呼吸的动态"代替"静态死板"或"乱漂的光球"
- 背景：**1 个极淡光晕**做**极缓呼吸**（12–18s 一次极小幅明暗起伏），替代 4 个高饱和漂浮光球（D1 已定：纸感 + 1 极淡光斑）。
- Hero 入场：内容 fade + 轻微上浮（0.6–0.8s ease-out），品牌光线随之亮起。
- 数据 / 统计用 **count-up 数字滚动**（已有 `ZgCountUp`），让首页"活"起来。
- 交互：卡片 hover 轻微上浮 + 阴影柔化；图标 / 光线有细微高光位移。
- 品牌光线可加一道**极慢流光（shimmer）**，但**只此一处**，绝不铺满。
- 节奏：动态要有"呼吸感"——动 → 静 → 动，不是持续嗡嗡漂。

**4.3.3 现代化**
- 当代网格与留白：Hero 大留白、清晰层级；模块间距遵循 8pt 节奏。
- 字号阶梯用 `--zg-fs-*`（修 BUG-07 后生效），标题衬线、正文无衬线，对比清晰。
- 圆角统一走主题变量；玻璃只用轻模糊 + 发丝描边 + 中性柔影。
- 图标统一墨金图标包（铁律 7），无 emoji 混搭。

**4.3.4 高级（premium）**
- 衬线标题（Noto Serif SC 自托管，D3）+ 收敛字距，金作点睛不铺满。
- 材质克制：纸感底 + 轻玻璃浮层 + 发丝金边 + 柔影，拒绝廉价大渐变与彩色长投影。
- 色彩克制：金 ≈5–8% 面积，其余是纸感中性色，留白即高级。

**4.3.5 活跃中带着沉稳（平衡法则）**
- 沉稳来自：稳定衬线排版、安静纸底、克制配色、充足留白、稳定网格。
- 活跃来自：金色光线母题、极缓呼吸光晕、count-up、hover 微动、品牌流光。
- 比例约 **70% 沉稳骨架 + 30% 活力点缀** → "稳而不死，活而不躁"。

**4.3.6 Do / Don't**
- ✅ 一道金色光线 + 一处呼吸光晕 + count-up + hover 微动 + 衬线留白
- ❌ 4 个高饱和漂浮光球、每卡 `blur(34px)` 重玻璃彩影、62px 渐变展示型标题（花里胡哨 / 阴郁）
- ✅ 衬线标题 + 纸感留白 + 发丝金边（高级 / 沉稳）
- ❌ 灰蒙蒙单色泥浆、无动态（死气沉沉）

## 8. 一句话总结

当前"更丑"是两个独立错误的叠加：**（a）墨金学术模式**背离了 1.0–4.0 已定义的「克制」语言，往花哨走了 4 轮；**（b）把墨金专属液态玻璃越界强加进经典模式**，违反铁律 2 的"两模式独立"。修法是：**经典保持原样橙玻璃**（越界样式回收）；**墨金回归克制为骨**——安静纸感底 + 沉稳金点睛 + 衬线标题 + 克制玻璃，并**叠加活力为魂**：以"追光=光"的品牌母题（一道金色光线）+ 有呼吸的动态（极缓光晕呼吸 / Hero 入场 / count-up / hover 微动）+ 现代化布局与留白，做到**活跃中带着沉稳、高级且有活力、不死气沉沉**；衬线在墨金下刻意做回并自托管加载；所有改动收口在 `.zg-inkgold` 作用域。
