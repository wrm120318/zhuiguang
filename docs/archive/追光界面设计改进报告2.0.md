## 1. 三大具体点（对应你提的反馈）

### 1.1 侧边栏 / 通知中心 圆角缺失（含 bug 修正）
**定位：**
- 管理后台侧边栏 `src/layouts/AdminLayout.vue` 的 `<aside class="sidebar">`：PC 端 `border-radius:0`、贴满左缘全高、无圆角。
- 通知中心 `src/components/NavBar.vue` 的 `noticeVisible` 抽屉（`el-drawer direction="rtl" size="380px"`）。
- 移动端菜单抽屉 `drawerVisible`（`el-drawer direction="ltr" size="72%"`）。

**bug 修正（main.css 内 `.zg-inkgold` 段）：**
- 删除 `.zg-inkgold .el-drawer.rtl, .zg-inkgold .el-drawer.ltr { animation: zgSheetUp … }` 这行错误覆盖（它把侧滑抽屉改成从底部上滑）。
- 改为尊重 Element Plus 原生侧滑动画（或新增正确水平滑入关键帧 `zgDrawerInR` / `zgDrawerInL`）。

**墨金作用域圆角方案（追加到 `.zg-inkgold`）：**
```css

  border-radius: 22px !important;

/* 移动菜单（从左滑入）→ 圆右侧 */
```

## 6. 风险与缓解

| 风险 | 缓解 |
|------|------|
| 个别图标组件名拼写错导致构建失败 | 实施时先 `import` 单点验证再批量替换；构建即暴露 |

| ECharts 金色调色板在深色背景下对比不足 | 仅墨金浅色背景套用；深色模式（阶段8）单独处理 |
