## 1. 现状设计系统全貌（基于真实源码）

读 `src/styles/main.css` 后确认，现状是一套**完成度很高的「浅黄橘黄小清新 + 毛玻璃 + H5 深度适配」设计系统**。

### 1.1 设计 Token（`:root` 真实默认值）

| Token | 当前值 | 含义 |
|-------|--------|------|
| `--zg-primary` | `#F59E0B` | 主色（橘） |
| `--zg-primary-2` | `#FB923C` | 辅色（深橘） |
| `--zg-accent` | `#FBBF24` | 点缀（亮黄） |
| `--zg-bg-from` / `-via` / `-to` | `#FFFBEB` / `#FEF3C7` / `#FDE68A` | 背景渐变三色 |
| `--zg-text` / `-dim` | `#78350F` / `#92400E` | 正文 / 次要文字（棕） |
| `--zg-card-bg` | `rgba(255,255,255,0.72)` | 卡片玻璃底 |
| `--zg-card-border` | `rgba(245,158,11,0.18)` | 卡片描边 |
| `--zg-radius` | `18px`（桌面 1280+ 为 `22px`） | 圆角 |
| `--zg-blur` | `16px`（移动端 `12px`） | 毛玻璃模糊 |
| `--zg-shadow` | `0 8px 32px rgba(245,158,11,0.12)` | 阴影 |
| `--zg-font` | 系统无衬线栈 | 字体 |
| `--zg-fs-scale` / `-xs…-2xl` | `1` / `11…32px` 缩放 | 字号系统（用户可缩放） |

### 1.2 现有视觉构件（真实类名）

- **动态渐变背景** `.zg-bg`：`linear-gradient(135deg, var(--zg-bg-from), var(--zg-bg-via), var(--zg-bg-to))`，`background-size:200% 200%`，`animation: zgGradientShift 22s` 持续位移。
- **漂浮光斑** `.zg-orb.a/.b/.c`：3 个 `blur(80px)`、`opacity:0.45` 的径向光斑，`animation: zgFloat 18s` 持续漂浮。
- **毛玻璃通用类** `.glass` / `.glass-strong`：`backdrop-filter: blur(var(--zg-blur)) saturate(180%)` + 半透明白底 + 橘色描边 + 阴影。
- **卡片悬停抬升** `.zg-card`：`translateY(-4px)` + 阴影加深。
- **渐变文字** `.zg-grad-text`：橘→黄渐变裁切文字。
- **Element Plus 全组件换肤**：`.el-button`（圆角 12px、主按钮橘渐变）、`.el-dialog`/`.el-message-box`（实色暖渐变 + 高光描边 + 居中）、`.el-drawer`（实色 `#FFFBEB`）、`.el-notification`（玻璃）、表格/标签/分页/菜单/滑块等全部橘色化。
- **移动端深度适配**：`@media (max-width:768px)` 缩小光斑/圆角、弹窗转窄；`@media (max-width:960px)` 管理路由隐藏全局导航；安全区 `env(safe-area-inset-bottom)`；宽屏 `1280+`/`1600+` 放大容器与圆角。

### 1.3 换肤引擎（后台「界面风格编辑器」）

- 存储：`themes` 表（`id / name / config(JSON) / is_active`）。`config` 为**自由 JSON**，可任意加字段，无需改表/迁移。
- 应用：`src/store/theme.ts` 的 `applyTheme(c)` 把 `config` 写进 `document.documentElement` 的 CSS 变量；`load()` 在 App 启动时拉 `GET /api/themes/active`（**无登录校验**）并应用到 `:root`。
- 发布：`ThemeView.vue` 调 `saveDraft({isActive:true})` → `PATCH /api/themes/:id/active`（超管专属）→ 全站所有人下次加载即生效（接口 ~30s TTL）。
- 当前可编辑维度：主色 / 辅色 / 点缀 / 背景渐变三色 / 毛玻璃强度(0–40) / 圆角(0–32)。

### 1.4 结论：现状已很强

不是「没设计的半成品」，而是有 token 体系、有动效、有 H5 适配、有实时换肤引擎的完整系统。问题集中在「度」与「层级」，不在「有没有」。

## 2. 不够「高级」的六大根因（按影响排序，附真实选择器）

| # | 根因 | 真实表现 | 为何显廉价 |
|---|------|----------|------------|
| 1 | 配色铺太满 | `.zg-bg` 渐变 + `.zg-orb`×3 + 主按钮渐变 + `.zg-grad-text` + 图标方块渐变，全站橘黄 | 糖果色/低龄感，与「中学学科平台 + 高级感」冲突 |
| 2 | 背景不安静 | `zgGradientShift 22s` + `.zg-orb` 持续漂浮 + `.zg-card` 弹入 | 工具站里持续运动显浮躁、伤专注，不利无障碍 |
| 3 | 毛玻璃滥用 | 每张卡 `.glass` 半透明压在彩色背景上（`--zg-card-bg:rgba(255,255,255,0.72)`） | 文字对比弱，像「花哨」不像「精致」 |
| 4 | 字体系统缺位 | `--zg-font` 全系统字体，标题仅靠 `font-weight:800` | 中文高级感常靠「衬线标题 + 无衬线正文」立住 |
| 5 | 品牌弱 + emoji 图标 | 导航/菜单/logo 全用 emoji（🌟🔍✉️🔔🚪） | 缺图形 logo / 线性图标集，不像「设计过」 |
| 6 | 深色/ECharts 未品牌化 | 深色只是 EP 默认；图表默认彩虹色 | 拖整体质感后腿 |

## 3. 墨金学术（Ink & Gold）完整提案

设计语言：**墨金学术**——以「纸感基底 + 沉稳金点睛 + 衬线标题 + 克制玻璃」替代现状的「全铺糖果橘」。

### 3.1 配色（重做色板）

- 基底：暖白纸感 `#FAF8F4`；正文墨字 `#1F2430`（替代现状棕字 `#78350F`，更中性高级）
- **强调色：沉稳金 `#BA7517`**（保留「光」的意象但降饱和），只用于按钮/激活态/重点
- 辅助中性灰阶承载 ~90% 界面；金仅做点睛，遵守「强调色 ≈ 5% 面积」法则，不铺背景
- 墨金预设 token（写入 `config`，见 §9.1）：`primary #BA7517` / `primary2 #854F0B` / `accent #EF9F27` / `bg #FAF8F4→#F5F1E8→#EFE9DC` / `text #1F2430` / `text-dim #5F5E5A`（注：text 变量现状未独立存储，墨金模式需在 `.zg-inkgold` 下覆写 `--zg-text` 等）

### 3.2 表面与材质（圆角 + 胶囊 + 液态玻璃分层）

- **圆角**：卡片 14/18 → 20–24px；弹窗随主题；统一 type scale
- **胶囊（999px）**：按钮 / 搜索框 / Tab / 分段控件 / 标签 chip / 头像 全部全圆角
- **液态玻璃只给浮层**：顶栏（`.nav`）、弹窗（`.el-dialog`）、抽屉（`.el-drawer`）、底部 TabBar 用 `backdrop-filter: blur() saturate()` + 顶部 1px 高光描边 + 柔投影
- **内容卡改用近实色白** + 1px 发丝边框 + 分层柔影，提升对比度到 WCAG AA

### 3.3 动效（安静化）

- 背景近静态（或 60s+ 极缓位移）；光斑减到 1 个、`opacity≈0.04`
- hover 只做 `-2px` 抬升 + 阴影加深，去掉弹入
- 尊重 `prefers-reduced-motion`，关闭漂浮/弹入

### 3.4 字体系统

- 标题衬线（Noto Serif SC / 思源宋体），正文无衬线
- 定义清晰字阶与字距纪律

### 3.5 品牌与图标

- 设计 SVG「光」mark + 衬线 wordmark「追光」替换 emoji（中远期，非本方案必须）
- 功能图标统一线性图标集（中远期）

### 3.6 深色模式 / 图表

- 深中性底 `#0F1115` + 浮起面 + 提亮金
- ECharts 注册「中性 + 金」品牌主题，弃用默认彩虹

## 4. 三要素可行性（液态玻璃 / 胶囊 / 圆角）

| 要素 | 可行性 | Web 实现真相 | 风险 / 红线 |
|------|--------|--------------|-------------|
| 圆角 | ✅ 零风险 | 调大 `--zg-radius` token | 无 |
| 胶囊 | ✅ 极低风险 | 元素 `border-radius:999px`，`:deep()` 覆 EP 组件 | 仅形态变化 |
| 液态玻璃 | ⚠️ 可近似（非 100% 还原） | `backdrop-filter` + 顶部高光描边 + 内高光 + 柔投影；Apple 原生折射（feDisplacementMap）Web 做不到，feTurbulence 折射安卓支持差、成本高，**不采用** | 性能（低端机 `backdrop-filter` 掉帧）、对比度/无障碍、iOS/安卓差异需 `background` 兜底 |

**学生机性能红线**：用户为中学生（50–60 人，手机可能中低端），`backdrop-filter` 一多就掉帧。故液态玻璃**只给浮层**，内容卡转实色；且因是全局开关，管理员可随时切回经典。

## 5. 超管一键切换架构（已确认可行）

### 5.1 为什么能「全站全用户」

`themes` 表 `config` 为自由 JSON；`GET /api/themes/active` **无鉴权**，前端 `load()` 在启动期写到 `:root`。任何访客（学生/教师/超管）拉到的都是同一个 active 主题 → **天然全站共享**。发布按钮文案即「全站即时生效」。

### 5.2 新增机制：`designMode`（皮肤开关）

- `ThemeView` 增加「设计模式」分段控件：`经典暖橘` / `墨金学术`。
- 选中后写入 `config.designMode`（自由 JSON 加一字段，**后端无需改表、无需迁移**）。
- `src/store/theme.ts` 的 `applyTheme(c)` 增加一行：
  ```ts
  root.classList.toggle('zg-inkgold', c.designMode === 'inkgold')
  ```
- 经典模式：`designMode` 为空或 `'classic'` → 移除 `zg-inkgold` 类 → 仅渲染基础样式。
- **墨金所有新样式全部写在 `.zg-inkgold { }` 作用域下**，移除类即完全消失。

### 5.3 后端影响

- `config` 是自由 JSON，`designMode` 自动随 `saveDraft` 存库，**零迁移**。
- 现有 `PATCH /api/themes/:id/active`、`POST/PUT /api/themes` 均已 `requireRole('SUPER_ADMIN')`，权限不变。
- 无新增接口（若做「一键预设」也复用现有 `saveDraft`）。

### 5.4 「一键切换」两种颗粒度（推荐）

- **核心（满足用户诉求）**：`设计模式` 分段控件 = 纯皮肤开关，**只切类、不动颜色**（即第三点第二种）。管理员想换金色调再用现有 6 个滑块微调，或点「套用墨金配色」预设。
- **便利（可选）**：两个预设按钮——「套用墨金学术全套」（皮肤+金色调）、「恢复默认橘黄」（皮肤+原始橘黄）。预设按钮会写颜色；而单纯拖动「设计模式」开关**绝不写颜色**，确保经典模式保留管理员自调配色。

## 6. 导航栏胶囊化方案（仅墨金模式）

### 6.1 现状真实结构（`NavBar.vue`）

- 根元素 `<header class="nav glass">`，样式：
  ```css
  .nav { position: sticky; top: 0; z-index: 100; border-radius: 0; border-left:none; border-right:none; border-top:none; }
  ```
  → 占满整行宽度、贴顶、无圆角。
- 内层 `<div class="nav-inner zg-container">`：`max-width:1240px; margin:0 auto` 已居中限宽。
- 激活链接 `.nav-link.active`：橘底；移动端 `.menu-btn` 显示汉堡。

### 6.2 墨金模式胶囊化（写在 `.zg-inkgold` 下）

```css
.zg-inkgold .nav {
  max-width: 1240px;
  margin: 14px auto 0;          /* 悬浮、不占满宽度 */
  border-radius: 999px;         /* 胶囊形 */
  border: 1px solid rgba(255,255,255,.5);
  background: rgba(250,248,244,.7);
  backdrop-filter: blur(20px) saturate(180%);
  -webkit-backdrop-filter: blur(20px) saturate(180%);
  box-shadow: 0 10px 40px rgba(31,36,48,.12);
}
.zg-inkgold .nav-inner { height: 60px; padding: 0 18px; }
.zg-inkgold .nav-link { border-radius: 999px; }      /* 链接也胶囊 */
.zg-inkgold .brand-name { font-family: 'Noto Serif SC', serif; } /* 衬线 wordmark */
```

效果：顶部一个**左右留白、两端圆润的悬浮金边玻璃胶囊**，里面链接同为胶囊；经典模式保持占满宽度原样（第 6.1 条规则完全不改动）。

## 7. 「切回经典 = 和现在完全一样」硬约束与实施铁律

这是用户最高优先级约束。保证手段：

1. **不修改任何现有基础 CSS 规则**：`main.css` / `NavBar.vue` / 各组件现有样式原样保留。墨金样式只追加在 `.zg-inkgold { }` 新块。
2. **不改 `:root` 默认变量值**：`--zg-primary` 等默认值保持橘黄，原样不动。墨金的颜色来自 `config`（运行时 `applyTheme` 覆盖），经典模式无 `designMode` → 不覆盖 → 回到默认橘黄。
3. **`designMode` 用「加/去类」实现**：墨金加 `zg-inkgold`，经典移除 → 浏览器只渲染基础样式，像素级回到现在。
4. **第三点决策（第二种）**：切换 `designMode` **只切皮肤、不动颜色**。若管理员曾自调配色，切回经典后保留其配色，仅皮肤复原为现状结构（占满宽度导航等）。
5. **一键「恢复默认橘黄」预设**（可选）才写回原始橘黄 token；纯开关不写。

> 验收时可逐页截图对比：经典模式 vs 当前生产站点，导航栏宽度/配色/emoji/卡片玻璃/动效应一致。

### 8.3 `store/theme.ts` 改动（仅加一行）

```ts
function applyTheme(c: any) {
  if (!c) return
  const root = document.documentElement
  root.style.setProperty('--zg-primary', c.primary)
  root.style.setProperty('--zg-primary-2', c.primary2)
  root.style.setProperty('--zg-accent', c.accent)
  root.style.setProperty('--zg-bg-from', c.bgFrom)
  root.style.setProperty('--zg-bg-via', c.bgVia)
  root.style.setProperty('--zg-bg-to', c.bgTo)
  root.style.setProperty('--zg-blur', c.blur + 'px')
  root.style.setProperty('--zg-radius', c.radius + 'px')
  // ↓ 新增：皮肤开关（经典移除类 → 基础样式；墨金加类 → 新样式）
  root.classList.toggle('zg-inkgold', c.designMode === 'inkgold')
}
```


## 13. 动画设计（手机化过渡，仅墨金模式）

### 13.1 设计哲学

- **克制、有意图，不堆量**。墨金模式用「手机 App 式」的页面空间感，替代现状的杂乱持续运动（3 光斑 + 22s 渐变 + 弹入）。
- 一切新动效**仅作用于墨金模式**：CSS 部分写在 `.zg-inkgold { }` 作用域；路由过渡用 store 条件启用。经典模式零加载、与现在逐帧一致（硬约束 §7）。
- 动效语气统一：只用一种缓动 `cubic-bezier(.22,1,.36,1)`（easeOutExpo，自然回弹）。

### 13.2 动效清单

| 动效 | 手机化表现 | 作用范围 |
|------|------------|----------|
| 路由 / 页面切换 | 新页从右滑入 + 轻微缩放/淡入，旧页向左滑出（iOS push 风格） | 仅墨金（`<router-view>` 条件 `<transition>`） |
| 底部上滑 sheet | 移动端弹窗/抽屉从底部往上滑出（sheet 感） | 仅墨金 |
| 底部导航 / Tab 切换 | 交叉淡入，不跳变 | 仅墨金 |
| 列表 / 卡片错落入场 | `IntersectionObserver` 逐条淡入上移（stagger） | 仅墨金 |
| 微交互 | 按钮按压缩放、卡片 hover 高光扫过、链接下划线展开、输入框聚焦光环 | 仅墨金（`.zg-inkgold`） |
| 图标 / logo 极淡呼吸 | 幅度极小，仅墨金 | 仅墨金 |
| 统一缓动 token | `cubic-bezier(.22,1,.36,1)` | 全局 token（不影响布局/颜色，仅动效语气） |

### 13.3 实施：路由过渡（App.vue）

条件启用：`designMode==='inkgold'` 用 `zg-page` 过渡，否则空字符串（经典无过渡）。

```vue

  <transition :name="theme.designMode === 'inkgold' ? 'zg-page' : ''" mode="out-in">
```

### 13.5 实施：错落入场（IntersectionObserver 组合式）

新增 `src/composables/useReveal.ts`，**仅墨金模式**初始化观察，给 `.zg-reveal` 元素加 stagger 入场：

```ts
// src/composables/useReveal.ts
import { onMounted, onBeforeUnmount, type Ref } from 'vue'
export function useReveal(root: Ref<HTMLElement | null>, selector = '.zg-reveal') {
  let io: IntersectionObserver | null = null
  onMounted(() => {
    // 经典模式（无 zg-inkgold 类）直接返回：元素保持原样，无隐藏、无动画
    if (!root.value || !document.documentElement.classList.contains('zg-inkgold')) return
    if (typeof IntersectionObserver === 'undefined') {
      root.value.querySelectorAll(selector).forEach(el => el.classList.add('zg-reveal-in'))
      return
    }
    io = new IntersectionObserver((entries) => {
      entries.forEach((e, i) => {
        if (e.isIntersecting) {
          ;(e.target as HTMLElement).style.transitionDelay = `${Math.min(i, 6) * 60}ms`
          e.target.classList.add('zg-reveal-in')
          io!.unobserve(e.target)
        }
      })
    }, { threshold: 0.12 })
    root.value.querySelectorAll(selector).forEach(el => io!.observe(el))
  })
  onBeforeUnmount(() => io?.disconnect())
}
```

配合 CSS（写在 `.zg-inkgold` 下）：
```css
.zg-inkgold .zg-reveal { opacity: 0; transform: translateY(18px);
  transition: opacity .5s cubic-bezier(.22,1,.36,1), transform .5s cubic-bezier(.22,1,.36,1); }
.zg-inkgold .zg-reveal-in { opacity: 1; transform: none; }
```
用法：列表容器 `const root = ref(null); useReveal(root)` + 模板 `ref="root"`，子项加 `class="zg-reveal"`。经典模式 `useReveal` 直接返回，元素不被隐藏。

### 13.7 统一缓动 token（全局，不影响外观）

在 `:root` 现有 token 下追加（经典模式也可用，仅影响动效语气，不改变布局/颜色）：
```css

```
各处墨金动效统一引用 `var(--zg-ease)`；基础样式现有 transition 不强制替换，避免影响经典表现。

### 13.8 无障碍与性能（硬性）

- 全部动效只用 `transform` / `opacity`（GPU 加速），**绝不**动画 `width/height/margin/top`（避免 layout 抖动、低端机掉帧）。
- 尊重 `prefers-reduced-motion`：
```css
@media (prefers-reduced-motion: reduce) {
  .zg-inkgold .zg-page-enter-active, .zg-inkgold .zg-page-leave-active,
  .zg-inkgold .zg-card::after, .zg-inkgold .logo, .zg-inkgold .zg-reveal,
  .zg-inkgold .el-drawer.rtl, .zg-inkgold .el-drawer.ltr {
    animation: none !important; transition: opacity .2s !important; transform: none !important;
  }
}
```
- 路由过渡 `mode="out-in"`，单程 ≤ .4s，避免等待感。
- `IntersectionObserver` 仅在墨金模式初始化，经典零开销。

### 13.9 经典模式零影响验证

- 经典模式：`theme.designMode !== 'inkgold'` → `<router-view>` 的 `:name` 为空 → Vue 不加任何过渡类；`.zg-inkgold` 不存在 → §13.4/13.6/13.8 所有 CSS 不生效；`useReveal` 直接 return。故经典模式表现与现状**完全一致**（无路由滑动、无微交互、无错落、无呼吸）。
- 验收：同 §11 第 3 条，切回经典后逐页对比生产站点，过渡动效应与现在相同（即基本无额外过渡）。

### 13.10 风险与缓解

| 风险 | 缓解 |
|------|------|
| 路由过渡页面「闪一下/重叠」 | 用 `mode="out-in"`；单程 ≤ .4s |
| 错落入场元素初始 `opacity:0` 若 JS 失效会不可见 | 仅墨金生效；`useReveal` 失败兜底（直接加 `zg-reveal-in` 或不观察）；IntersectionObserver 不支持时直接显示 |

| 经典模式被意外影响 | 全部作用域 / 条件锁定墨金，§13.9 验证 |
