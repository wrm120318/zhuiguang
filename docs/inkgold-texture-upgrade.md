# 追光·墨金学术主题 — 全站质感升级设计（柔光玻璃 + 主题背景）

> 状态：设计稿 v1（**已于 v3.0.0 / 2026-08-22 落地，背景图采用 SVG 程序化方案**：`public/bg/inkgold-paper.svg` + `inkgold-paper-dark.svg`）
> 范围：仅 `.zg-inkgold` / `.zg-inkgold-dark` 作用域（铁律2）；经典 :root 像素级不动（铁律1）
> 目标：对标 OPPO / vivo / 华为 / 小米 / 苹果 级「真柔光玻璃」——背景有图、玻璃透光、阴影似有似无

---

## 0. 用户本轮反馈（原始诉求提炼）

1. **Hero 阴影太大太深太明显** —— 当前 `box-shadow` 第二层 `0 56px 130px -32px rgba(120,90,30,.18)` 需收敛为「似有似无」。
2. **现有设计丑、被旧范式束缚** —— 要求「敢于重新设计」，不修补、重构。
3. **移动端 hero 太大** —— 移动端整体缩放需收敛（标题、padding、stats 密度）。
4. **全站柔光玻璃仍不行** —— 与大厂差距大，根因是当前玻璃是「白瓷不透光 + 硬阴影撑立体」，而非「背景图透上来 + 极低不透明度玻璃 + 细高光」。
5. **加整体主题背景** —— 浅色图片 + 淡淡图案，贴合暖金学术配色，让玻璃「有东西可透」。
6. **先写设计 MD，做好准备**（未说"做" → 本文档不触发任何代码改动）。

## 1. 根因诊断（为什么现在不像大厂柔光玻璃）

| 维度 | 现在（v3 现状） | 大厂柔光玻璃 |
|---|---|---|
| 背景 | 纯 CSS 渐变光晕（`.zg-bg` + 3 个 `.zg-orb`），无图、无纹理 | 浅色基底图 + 极淡图案/光斑，玻璃透出底图层次 |
| 玻璃透明度 | `rgba(255,255,255,0.70)` 偏高 → 不透 | `rgba(255,255,255,0.35~0.55)` + 强 blur，背景透上来 |
| 立体感来源 | 靠大 blur 重阴影撑（`130px/.18`） | 靠**顶部细高光 + 极淡负扩散柔影**，阴影几乎不可见 |
| Hero 边界 | 仍是大圆角卡 + 重投影（虽去硬边但有 130px 影） | 边界虚化、与背景晕开，无明确矩形投影 |
| 移动端 hero | padding 30px / 标题 33px / stats 三列 → 偏大 | 紧凑、留白克制、字号收敛 |

**结论**：质感差距 ≈ 90% 来自「背景没有图 + 玻璃不透 + 阴影太硬」，不是颜色问题。

---

## 2. 总体方案：三层背景体系 + 真柔光玻璃

### 2.1 新增「主题背景图」层（核心升级）

在 `App.vue` 现有 `.zg-bg` + `.zg-orb` 之前，新增一层**浅色基底图**：

```
<div class="zg-root">
  <div class="zg-bgimg"></div>   ← 新增：浅色主题图（含淡图案）
  <div class="zg-bg"></div>      ← 现有：暖金渐变光晕（调淡）
  <div class="zg-orb a/b/c"></div> ← 现有：光球（调淡/收敛）
  ...
</div>
```

- **图片来源**（零外部 CDN 依赖，自托管，符合铁律）：
  - 方案 A（推荐）：用 **SVG 程序化生成**一张浅暖色基底图（细微网格/斜纹/光斑噪点），内联为 `public/bg/inkgold-paper.svg` 或 base64 进 CSS。优点：体积小（<30KB）、可控、永不 404。
  - 方案 B：下载一张免版税浅色抽象图（如 Unsplash 暖米白纸张/柔光），压缩到 `public/bg/inkgold-paper.jpg`（~80-150KB），`object-fit:cover` 铺满。
  - **图案风格**：与暖金学术契合——极淡的「宣纸纤维 / 细网格 / 斜向丝光」纹理，透明度 0.04~0.08，肉眼几乎只见层次、不见图案。
- **配色贴合**：基底图主色 `#FAF8F4` 暖米白，叠加 `rgba(212,175,55,0.05)` 淡金光斑，与现有 `--zg-bg-*` 一致。
- **深档**：深档用 `inkgold-paper-dark`（温润暖黑 `#1B1710` 基底 + 极淡金点），玻璃透出暖黑层次。
- **性能**：`background-attachment: fixed` 或 `position:fixed; inset:0; z-index:-2`，单图加载一次，不随滚动重绘。

### 2.2 背景层次收敛（调淡现有光晕）

- `.zg-bg` 径向光晕透明度 `.13/.09/.08` → 降到 `.08/.05/.05`，避免抢戏。
- `.zg-orb` opacity `0.42` → `0.22`，blur 保持大但更隐。
- 目的：背景图成为主角，光晕只做「补光」，不再喧宾夺主。

## 3. 真柔光玻璃材质规范（全站统一）

### 3.1 玻璃 token 重定义（main.css 墨金变量块）

```css
html.zg-inkgold {
  --zg-glass-bg: rgba(255,255,255,0.42);      /* 原 0.70 → 透 */
  --zg-glass-bg-2: rgba(255,250,240,0.30);
  --zg-glass-blur: 22px;                        /* saturate(180%) */
  --zg-glaze: inset 0 1px 0 rgba(255,255,255,0.9);  /* 顶部细高光，关键 */
  --zg-soft-1: 0 2px 10px -4px rgba(120,90,30,0.10); /* 似有似无 */
  --zg-soft-2: 0 10px 30px -14px rgba(120,90,30,0.10);
  /* 移除原 --zg-shadow 的 56px/130px 重影 */
}
```

### 3.2 通用玻璃类（替换现有 .glass / .el-card / 弹窗）

```css
.zg-inkgold .glass,
.zg-inkgold .glass-strong,
.zg-inkgold .el-card {
  background: linear-gradient(155deg, var(--zg-glass-bg), var(--zg-glass-bg-2));
  -webkit-backdrop-filter: blur(var(--zg-glass-blur)) saturate(180%);
  backdrop-filter: blur(var(--zg-glass-blur)) saturate(180%);
  border: 1px solid rgba(255,255,255,0.35);   /* 仅顶部可见的细边，非硬框 */
  box-shadow: var(--zg-glaze), var(--zg-soft-1);
}
```

**关键差异**：阴影从 `0 56px 130px -.18` → `0 10px 30px -14px .10`，Hero 不再有「明显矩形投影」。

### 3.3 弹窗 / 抽屉（液态玻璃）

- 同上玻璃规范，但 `blur` 提到 `26px`，边框 `rgba(186,117,23,0.18)` 极淡金。
- 顶部高光 `inset 0 1px 0 rgba(255,255,255,0.8)` 保留（这是「玻璃感」灵魂）。
- **已确认删除**上下硬线（上轮已落，本稿继承）。

## 4. Hero 重新设计（敢于打破旧范式）

### 4.1 桌面 Hero

- **取消大圆角卡 + 重投影**。改为：随背景图晕开的「开放釉光区」——左右/上下用径向渐变把边缘化开，无明确矩形边界。
- 阴影：`var(--zg-glaze), 0 12px 36px -18px rgba(120,90,30,0.10)`（极淡，仅「浮」不「框」）。
- 内容：左文案（标题衬线 Noto Serif SC）+ 右视觉资产（光盘弱化或换为主题图案小卡）。
- 釉光：`hero-glaze` 斜向高光保留但透明度再降一档。

### 4.2 移动端 Hero（重点收敛）

| 项 | 现状 | 新方案 |
|---|---|---|
| padding | `30px 22px 28px` | `22px 18px 20px` |
| 标题 | `clamp(27px,8.2vw,33px)` | `clamp(22px,6.5vw,27px)` |
| slogan | `14px` | `13px`，行高 1.7 |
| stats | 3 列 `auto-fit minmax(72px)` | **2 列固定** + 更紧密度（`gap:10px 8px`，每片 `padding:10px 12px`，num `20px`） |
| 整体 | 偏大 | 紧凑、留白克制，与卡片节奏一致 |

> 理由：移动端 hero 不应比下方内容块更「重」。收敛后视觉重心回到内容。

## 5. 深档（`.zg-inkgold-dark`）同步规范

- 背景图：`inkgold-paper-dark`（暖黑 + 淡金点）。
- 玻璃：`rgba(40,33,22,0.40)` + `blur(22px)` + `inset 0 1px 0 rgba(255,243,214,0.10)`。
- 阴影：`0 12px 36px -18px rgba(0,0,0,0.40)`（深底深影，但同样「似有似无」）。
- 特异性铁律：深档选择器 `html.zg-inkgold.zg-inkgold-dark`（0,2,1）≥ 浅档 `html.zg-inkgold`（0,1,1），否则深档不生效（铁律8）。

## 6. 后台自定义功能联动（铁律5 / 11）

- 新增背景图**不影响**后台自定义链路：
  - `quickLinks / s.color / siteConfig / 公告 / 主题切换` 配置→保存→发布→前台生效→回显 全链路不变。
  - 后台若自定义了主色（`--zg-custom-primary`），玻璃高光/边框金仍走 `rgba(var(--zg-primary-rgb),a)` 通道变量（铁律9），自动跟随。
  - 背景图是「统一默认呈现」，后台未自定义时走默认；后台自定义色值照常生效。
- 后台 UI 自身（侧边栏/弹窗）同步吃新玻璃规范，回归验证。

## 9. 待用户拍板的分叉点

1. **背景图来源**：SVG 程序化（推荐，零依赖）vs 下载压缩图（更"真实"但需确认版权/体积）。
2. **图案风格**：宣纸纤维 / 细网格 / 斜向丝光 / 光斑噪点 —— 选一种或组合。
3. **玻璃不透明度**：0.42（保守透光）vs 0.35（更透更大厂感，但文字对比需测试）。
4. **移动端 stats 列数**：2 列（推荐）vs 保持 auto-fit。
