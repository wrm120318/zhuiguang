追光 · 部署向导

跟着 7 步做，最多 10 分钟上线。所有自动化代码我都已经写好了。
✅ 本地构建已通过 ✅ 生产模式 HTTP 200 ✅ 数据库自动初始化 ✅ Render 配置已就位
1

推代码到 GitHub 2 分钟

先在 GitHub 新建空仓库（名字随便，不要勾选任何模板，不要加 README）。

📋 点我展开：在本项目目录复制这 3 行命令 
git remote add origin https://github.com/<你的 GitHub 用户名>/zhuiguang.git
git branch -M main
git push -u origin main
2

注册 Turso（数据库，免费 9GB）2 分钟

用 GitHub 一键登录，创建一个数据库，名字随意。

🔗 打开 Turso

创建完成后，复制下面两个值，一会儿粘贴到 Render：

TURSO_DATABASE_URL
libsql://xxx.turso.io
TURSO_AUTH_TOKEN
Create Token → 生成的 token
3

注册 Supabase（文件存储，免费 1GB）3 分钟

New Project → 等 2 分钟初始化 → 创建存储桶。

🔗 打开 Supabase

📌 关键步骤（少一个就上传不了文件）：

① 左侧菜单 Storage → New Bucket → 名称填 zhuiguang-files → 勾选 Public → Create

② 左侧底部 Settings → API → 复制 Project URL 和 service_role key（不是 anon key，长的那个）

SUPABASE_URL
https://xxx.supabase.co
SUPABASE_SERVICE_KEY
service_role 的长 key
SUPABASE_BUCKET
zhuiguang-files
⚠️ 3 个小坑：
· Bucket 必须是 Public，不然前端打不开图片
· 用的是 service_role key，不是 anon key
· 免费套餐有 50MB / 月 API 限额上限，小站够用
4

Render 新建 Web Service1 分钟

🔗 打开 Render 控制台

→ New → Web Service → 连接第 1 步的 zhuiguang 仓库

→ Render 会自动读取仓库根目录的 render.yaml，不用手动改任何配置

→ 点 Create Web Service

5

填环境变量（最重要的一步）3 分钟

在 Render 服务页 → 左侧 Environment → Environment Variables → 一条条 Add：

TURSO_DATABASE_URL
第 2 步拿到的值
TURSO_AUTH_TOKEN
第 2 步拿到的值
SUPABASE_URL
第 3 步拿到的值
SUPABASE_SERVICE_KEY
第 3 步拿到的值
SUPABASE_BUCKET
zhuiguang-files
JWT_SECRET
让 Render 自动 Generate（不用手动填）

保存后 Render 会自动触发重新构建。

6

等部署2-5 分钟

看 Logs 里出现下面两行 = 成功：

[storage] Supabase Storage 模式：文件存于云端 bucket
[server] 追光后端运行于 http://localhost:xxxx

顶部出现绿色 Live 按钮，就是成功了。

💡 报错？
常见错误 1：Turso URL/token 填错 → 检查 `libsql://` 开头没？
常见错误 2：Supabase service_role key 用成了 anon → 上传/下载会 403
7

登录，享受 ✨

访问分配的域名，形如 https://zhuiguang.onrender.com：

超管账号：admin / admin123456

登录后 → 管理 → 用户管理 改密码；→ 管理 → 经验设置 / 功能开关 自定义平台。
